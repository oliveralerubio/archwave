# Archwave - Vaporwave Theme for Omarchy

> Fork of [davidguttman/archwave](https://github.com/davidguttman/archwave) updated for **Omarchy 4**:
> adds `colors.toml` (Omarchy 4 generates the bar, terminals and apps from it; the original had none,
> so the bar and apps stayed unthemed), a recoloured `unlock.png` / `preview-unlock.png`, and removes
> the Omarchy 3 files (`waybar.css`, `walker.css`, `mako.ini`, `hyprland.conf`, `hyprlock.conf`, `swayosd.css`)
> that Omarchy 4 no longer reads.

A dreamy vaporwave aesthetic theme featuring pastel pinks, purples, and cyans with a retro-futuristic atmosphere.

## To install:
1. Copy the theme repository URL
2. Click `SUPER + ALT + SPACE`
3. Click `Install`
4. Click `Style`
5. Click `Theme`
6. Paste the link and hit enter to submit

### 2nd way to install
```bash
omarchy theme install https://github.com/oliveralerubio/archwave
```
